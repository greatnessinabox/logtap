# Changelog

All notable changes to LogTap will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [3.0.0] - 2026-01-26

### Added
- Complete rewrite with modern architecture
- Semantic search with natural language queries
- Anomaly detection and pattern learning
- Timeline visualization with density chart
- Session diffing for comparing log sessions
- Deep object snapshots (values captured at log time)
- Multi-format export (Plain, Markdown, JSON, CSV)
- Built-in data anonymization for exports
- Causality grouping for request/response chains
- Tag auto-detection from common logging patterns
- Clickable file links with editor integration (VS Code, Cursor, WebStorm, etc.)
- Keyboard shortcuts for common actions
- IndexedDB persistence across page reloads

### Changed
- Migrated to Manifest V3
- New modern UI design
- Improved performance for high-volume logging

## [2.0.0] - Previous Version

Initial public release with basic log capture and filtering.
